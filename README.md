# 黑马记账

黑马记账是一款本地优先的个人桌面收支记账软件。它不需要注册、不需要登录，也不依赖网络；账目默认只保存在你自己的电脑上。

## 已实现功能

- 快速新增、编辑和二次确认删除收入或支出
- 退款/报销关联原支出、可选不计入统计
- 搜索、自定义日期、收支日历，以及今日/本周/本月/今年/全部账单
- 今日、本周、本月、今年或自定义时段统计，并与上一周期比较
- 月度总预算和分类预算、快捷模板与到期后手动确认的周期模板
- 18个系统一级分类、83个系统二级分类，以及用户自定义两级分类
- 记账表单内直接新增分类；系统分类锁定，自定义分类可编辑和安全停用
- 白瓷底黑马鎏金应用图标、28格统一3D分类图标和精修品牌界面
- 页面分层进入、金额滚动、图表生长、保存成功反馈、列表补位与主题过渡动效
- 桌面侧边导航；760像素窄窗口自动切换为未来手机式底部导航
- CSV 导入、查重和自动备份；CSV 导出与完整备份恢复
- 本机数字隐私密码（防随手查看，不等同于数据库加密）
- 黑马经典、暖阳活力、云朵治愈三套心情主题，可在任意页面快速切换；另保留深海专注主题
- 每套心情主题都可分别使用浅色、深色或跟随系统
- 1.5.0免安装预览版已经生成；Windows安装版和单文件便携版等待用户体验确认后再制作

## 普通用户

当前唯一推荐入口是根目录的 `00-点我打开黑马记账-当前最新版.cmd`，直接双击即可打开1.5.0免安装预览版。先阅读 [请先看这里](00-请先看这里.md) 和 [用户指南](docs/USER_GUIDE.md)。

`可直接打开-黑马记账-1.5.0预览版` 是当前免安装程序的完整目录；旧预览目录与 `release` 中的1.0.0/1.1.0成品都不用于检查本次新版界面。

如果你只是想知道项目里这些文件分别做什么、哪些不能删除，请看 [项目文件地图](docs/FILE_GUIDE.md)。

Git可以理解为代码的“游戏存档系统”。双击 `00-查看Git存档点.cmd` 可以安全查看现有存档，不会修改文件；回档前请先阅读 [Git小白指南](docs/GIT_GUIDE.md)。
