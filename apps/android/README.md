# 黑马记账 Android App

## 当前状态

这里是与Windows桌面版完全分开的Android原生工程。第一阶段“可安装视觉体验版”已经完成，版本为 `0.1.0-visual`。

当前版本可以在Android 10及以上手机安装并体验：

- 首页、统计、记账、预算、我的五项底部导航。
- Liquid Glass与自然治愈两套整体主题。
- 玻璃按压、页面弹性切换、金额滚动和记账面板展开。
- 系统省电模式自动降低装饰效果，另有手动省电和减少动效选项。
- 收入/支出切换、立体感快捷分类和金额数字键盘的视觉交互。
- 白底彩色图标、圆形自适应图标和Android主题着色图标。

当前版本明确还没有接入正式数据库，记账、预算、分类管理、备份等入口中的内容不会持久保存。界面会如实提示“视觉体验版”，不生成虚假账目。

## 唯一推荐体验入口

普通用户不需要Android Studio，也不需要运行代码。请把以下文件复制到安卓手机后安装：

`../../手机安装包/黑马记账-Android-视觉体验版-0.1.0.apk`

逐步安装说明见：`../../手机安装包/手机安装说明.txt`。

## 工程边界

- Android源码在本目录。
- Windows桌面版仍在 `../windows-desktop`，没有被删除或覆盖。
- Android设计与技术文档在 `../../docs/android`。
- 高保真确认图在 `../../design/android`。
- 大型依赖和缓存位于 `D:\AndroidDev`，没有修改Windows系统PATH。

开发者构建和测试方式见 `../../docs/android/BUILD_AND_TEST.md`。
