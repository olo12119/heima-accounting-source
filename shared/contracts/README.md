# 跨端数据协议预留区

这里将来用于定义Windows版和Android版都能理解的备份文件格式。可以把它理解成两个App之间共用的“搬家箱标准”。

当前只创建说明，**没有擅自改动Windows备份格式，也没有生成未经验证的Android数据结构**。

正式开发Android数据层时，需要先：

1. 读取并固定当前Windows完整备份的版本、字段和SHA-256校验规则。
2. 用共享的测试样例确保两端对金额、日期、分类和退款关系的理解完全一致。
3. Android导入前先校验，生成安全备份，再以数据库事务完整替换；失败时不覆盖原账目。

在这些测试完成以前，不宣称Windows和Android已能安全互导数据。
