# 黑马记账产品文档

## 产品定位与用户

黑马记账是面向中国大陆普通个人用户的桌面收支记账工具。它帮助用户用几秒钟记下收入与日常花销，并清楚看到钱从哪里来、花到哪里去。产品坚持简单、快速、清晰、本地优先、无需账号和无需联网，不承担企业会计、报税或资产管理职责。

默认语言为简体中文，默认货币为人民币 CNY（¥），首发支持 Windows，并使用同一套主要代码支持 macOS。

## 当前范围与页面

### 首页

- 当前结余、今日与本月收支、预算进度和待确认模板。
- 最近7天收入与支出资金流。
- 最近五笔收支，可直接点击编辑。
- 本月支出一级分类占比。
- 始终可见的“记一笔”快速入口。
- 无数据时显示真实空状态，不植入示例账目。

### 记一笔

- 先选择收入或支出，再输入人民币金额；支持 `12.50`，只允许正数和最多两位小数。
- 选择一级、二级分类；二级分类必须属于选中的一级分类。
- 无需离开表单即可新建一级分类或给当前一级分类增加二级分类，已有金额和备注不会丢失。
- 收入可标记为普通收入、退款或报销；退款/报销必须关联原支出，统计时用于抵扣对应支出而不是虚增收入。
- 可把特殊账目标记为“不计入统计”，账单保留但预算与趋势忽略它。
- 默认当前本地日期与时间，可填写200字以内备注。
- 收入与支出使用各自分类；展示最近30天同类型常用分类，并提供合理默认快捷项。
- Enter 保存、Esc 关闭，保存后所有摘要与统计同步刷新。

### 账单与日历

- 今天、本周、本月、今年、全部和自定义日期范围；中国习惯的一周从周一开始。
- 可按备注、分类名称或金额搜索。
- 可筛选全部收支、仅支出或仅收入；按日期分组，展示每日收入、支出小计。
- 日历视图按天显示收支，点击日期可直接查看当天账目。
- 组内按时间倒序显示收支类型、金额、分类和备注。
- 支持编辑；删除必须经过二次确认，取消不会改变数据。

### 统计

- 今日、本周、本月、今年或自定义日期范围，并可分别分析支出或收入。
- 对所选收支类型展示一级分类占比和金额排行。
- 按本地自然日生成收支趋势；没有记录的日期补零。
- 显示上一周期金额和增减比例，帮助判断变化。

### 预算与计划

- 可设置每月总预算以及一级支出分类预算；预算只提醒，不阻止继续记账。
- 可创建一次性快捷模板或每周、每月、每年周期模板。
- 周期模板到期后由用户点击确认生成，不在后台偷偷写入账目。

### 数据与设置

- 黑曜鎏金、极光深海、琥珀日落、紫晶暮色四套颜色主题。
- 每套颜色主题均可选择浅色、深色或跟随系统。
- 导出全部账目为 Excel 友好的 UTF-8 CSV。
- 从常见中文 CSV 导入账目；导入前预览有效、无效和重复数量，导入前自动备份，重复账目自动跳过。
- 导出完整备份，从备份完整恢复。
- 可设置4至12位本机数字隐私密码，重启后需解锁。
- 显示真实数据库路径和本地保存状态。

### 分类管理

- 系统预设分类始终锁定，用户不能改名、换图标、删除或改变收支类型。
- 用户可以创建自己的一级分类，也可以在系统或自定义一级分类下添加自定义二级分类。
- 分类管理页和记账表单都能新增分类。
- 自定义一级分类可选择28种3D图标和经过设计的颜色。
- 自定义分类可改名、排序、停用和重新启用。
- 没有账目使用的自定义分类可以删除；已经被账目使用的分类只能安全停用，历史账目继续正常显示。
- 收入和支出分类保持隔离，二级分类始终属于一个明确的一级分类。

## 数据字段

每笔账目包含收支类型、业务类型（普通/退款/报销）、唯一编号、整数分金额、一级分类、二级分类、本地日期、本地时间、备注、是否排除统计、关联原支出、创建时间和更新时间。分类同时保存系统/自定义标记、启用状态、图标、颜色和顺序，并标记适用的收支类型，禁止支出误用收入分类。

## UI 设计

- 桌面侧边导航：首页、账单、统计、分类管理、预算与计划、数据与设置。
- 760像素窄窗口使用手机式底部导航、单列内容和悬浮记账按钮；当前仍为Windows桌面程序，不宣称已经生成手机App。
- 收入使用翡翠绿、支出使用暖珊瑚色；品牌配色可以在四套低饱和主题间切换。
- 应用图标使用AI绘制的黑马鎏金轻量3D标识；分类使用原创黏土质感3D图集、渐变底板与立体微动效。
- 页面分层进入，金额平滑滚动，图表绘制生长，弹窗弹性出现，账目删除后列表平滑补位；鼠标悬停提供轻微抬升和光影反馈。
- 动效以不阻塞操作为前提，并尊重系统“减少动画”设置，不使用持续粒子、夸张翻转或长时间等待。
- 提供键盘焦点、错误提示、空状态、加载状态和足够的文字对比度。

## 当前明确不做

因为本软件只供用户本人和周边人使用，以下面向大规模公众或商业运营的功能暂不加入：银行/支付平台自动同步、账号和云同步、家庭多人共享、投资行情与复杂资产管理、多币种、发票OCR、AI消费建议、企业报销审批、自动更新服务器、原生移动端和多人协作。它们会增加账号成本、隐私风险、维护工作和界面复杂度，却不是小范围自用的刚需。当前窄屏布局只是为未来手机版降低改造成本，不能把Windows程序直接安装到手机。

## 后续扩展原则

只增加真实使用中反复遇到的本地功能。新功能应先说明使用场景、复杂度和数据影响，再决定是否加入，不以“市面上有”作为开发理由。
