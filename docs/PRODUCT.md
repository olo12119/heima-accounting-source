# 黑马记账产品文档

## 产品定位与用户

黑马记账是面向中国大陆普通个人用户的桌面收支记账工具。它帮助用户用几秒钟记下收入与日常花销，并清楚看到钱从哪里来、花到哪里去。产品坚持简单、快速、清晰、本地优先、无需账号和无需联网，不承担企业会计、报税或资产管理职责。

默认语言为简体中文，默认货币为人民币 CNY（¥），首发支持 Windows，并使用同一套主要代码支持 macOS。

## 第一版范围与页面

### 首页

- 今日、本月收入与支出，以及本月结余。
- 最近五笔收支，可直接点击编辑。
- 本月支出一级分类占比。
- 始终可见的“记一笔”快速入口。
- 无数据时显示真实空状态，不植入示例账目。

### 记一笔

- 先选择收入或支出，再输入人民币金额；支持 `12.50`，只允许正数和最多两位小数。
- 选择一级、二级分类；二级分类必须属于选中的一级分类。
- 默认当前本地日期与时间，可填写200字以内备注。
- 收入与支出使用各自分类；展示最近30天同类型常用分类，并提供合理默认快捷项。
- Enter 保存、Esc 关闭，保存后所有摘要与统计同步刷新。

### 账单

- 今天、本周、本月、全部四个范围；中国习惯的一周从周一开始。
- 可筛选全部收支、仅支出或仅收入；按日期分组，展示每日收入、支出小计。
- 组内按时间倒序显示收支类型、金额、分类和备注。
- 支持编辑；删除必须经过二次确认，取消不会改变数据。

### 统计

- 今日、本周、本月切换，并可分别分析支出或收入。
- 对所选收支类型展示一级分类占比和金额排行。
- 按本地自然日生成收支趋势；没有记录的日期补零。

### 数据与设置

- 浅色、深色、跟随系统。
- 导出全部账目为 Excel 友好的 UTF-8 CSV。
- 导出完整备份，从备份完整恢复。
- 显示真实数据库路径和本地保存状态。

## 数据字段

每笔账目包含收支类型、唯一编号、整数分金额、一级分类、二级分类、本地日期、本地时间、备注、创建时间和更新时间。分类同时标记适用的收支类型，禁止支出误用收入分类。

## UI 设计

- 桌面侧边导航：首页、账单、统计、数据与设置。
- 石墨绿作为品牌底色，收入使用翡翠绿、支出使用暖珊瑚色，并通过低饱和辅助色区分分类。
- 每个一级分类使用有语义的 Lucide 矢量图标和独立柔和底色；卡片、边框、阴影和动效保持克制。
- 提供键盘焦点、错误提示、空状态、加载状态和足够的文字对比度。

## 第一版不做

预算、资产负债、云同步、登录、多账本、周期账单、自定义分类管理、CSV 导入、自动更新、手机端以及多人协作暂不包含。

## 后续扩展方向

优先考虑预算提醒、多账本、自定义分类、周期账单；这些功能应继续遵守本地优先和低学习成本原则。
