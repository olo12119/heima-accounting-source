# 黑马记账项目文件地图

这份说明专门写给不懂编程的项目负责人。整理后，根目录像一个总文件柜，Android 工程、文档、设计稿和安装包各有自己的抽屉。

## 最重要的入口

| 你想做什么 | 打开什么 |
| --- | --- |
| 体验当前Android成果 | 把 `手机安装包/黑马记账-Android-正式版-1.1.0.apk` 复制到安卓手机并安装 |
| 阅读Android设计方案 | 打开 `docs/android/README.md` |
| 查看Git“游戏存档” | 双击 `scripts/查看Git存档点.cmd` |
| 了解当前状态 | 打开根目录 `00-请先看这里.md` |

Android 当前已有 1.1.0 正式版 APK；1.0.3 及更早版本只用于覆盖升级验证。

## 根目录的文件夹

| 文件夹 | 通俗解释 | 能否随便删除 |
| --- | --- | --- |
| `.git` | Git的“存档库”，包含历史存档 | **不能** |
| `apps/android` | Android原生App源码、测试和构建脚本 | **不能** |
| `design/android` | 已确认的高保真页面、组件和动效原型 | **不能** |
| `手机安装包` | 当前/历史Android APK和给普通用户的安装说明；APK本身不进Git | 安装前**不能随便删除** |
| `docs/android` | Android产品、界面、主题、动效、技术和验收方案 | **不能** |
| `docs` | 项目说明、报告和真实开发日志 | **不能** |
| `scripts` | 快捷启动脚本（查看存档、用 Android Studio 打开） | **不能** |
| `shared/contracts` | 未来搬迁备份时的共用标准预留区 | **不能** |

## 程序文件与个人账目不是一回事

Android 账目保存在手机 App 私有数据库中，卸载 App 可能删除数据。Git 保护的是工程源码和文档，不是个人账目。账目应使用 App 内“完整备份”，并把备份复制到另一个安全位置。
