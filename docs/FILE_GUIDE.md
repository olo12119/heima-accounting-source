# 黑马记账项目文件地图

这份说明专门写给不懂编程的项目负责人。整理后，根目录像一个总文件柜，Windows和Android分别有自己的抽屉。

## 最重要的入口

| 你想做什么 | 打开什么 |
| --- | --- |
| 体验当前Android成果 | 把 `手机安装包/黑马记账-Android-视觉修正版-0.2.0.apk` 复制到安卓手机并安装 |
| 打开旧Windows桌面版 | 双击根目录 `00-打开Windows桌面版-1.5.0.cmd` |
| 阅读Android设计方案 | 打开 `docs/android/README.md` |
| 查看Git“游戏存档” | 双击根目录 `00-查看Git存档点.cmd` |
| 了解当前状态 | 打开根目录 `00-请先看这里.md` |

Android当前已有0.2.0视觉修正版APK；旧0.1.0只用于对比。当前还没有正式数据库，APK不能永久保存账目。

## 根目录的文件夹

| 文件夹 | 通俗解释 | 能否随便删除 |
| --- | --- | --- |
| `.git` | Git的“存档库”，包含历史存档 | **不能** |
| `apps/windows-desktop` | Windows桌面版的全部源码、测试、开发工具和预览成品 | **不能整体删除** |
| `apps/android` | Android原生App源码、测试和构建脚本 | **不能** |
| `design/android` | 已确认的高保真页面、组件和动效原型 | **不能** |
| `手机安装包` | 当前/历史Android APK和给普通用户的安装说明；APK本身不进Git | 安装前**不能随便删除** |
| `docs/android` | Android产品、界面、主题、动效、技术和验收方案 | **不能** |
| `docs` | 项目说明、Windows用户指南和真实开发日志 | **不能** |
| `shared/contracts` | 未来Windows和Android搬迁备份时的共用标准预留区 | **不能** |

## Windows抽屉里有什么

`apps/windows-desktop` 内部仍然保留了原有Electron项目的完整结构：

| 名称 | 用途 | Git是否保存 |
| --- | --- | --- |
| `src` | 界面、数据库、安全桥接和业务规则的源码 | 是 |
| `tests` | 自动检查功能是否正常的测试代码 | 是 |
| `assets`、`build`、`scripts` | 品牌素材、构建图标和辅助脚本 | 是 |
| `package.json`及各类配置 | 依赖清单和开发、测试、打包规则 | 是 |
| `node_modules` | 可重新下载的第三方程序零件 | 否 |
| `.cache`、`out`、`test-results` | 可重新生成的缓存、构建和测试临时文件 | 否 |
| `可直接打开-黑马记账-1.5.0预览版` | 当前免安装Windows成品的完整目录 | 否，但当前打开软件需要它 |
| `release` | 历史安装包和便携版，当前主要是旧1.0.0/1.1.0 | 否 |

Git不保存不代表“没有用”；只表示这些内容体积大、可重建或只属于当前电脑。任何清理仍需在说明影响并得到你同意后进行。

## 程序文件与个人账目不是一回事

Windows个人账目位于：

```text
%APPDATA%\HeimaAccounting\data\heima-accounting.sqlite3
```

这次目录整理没有移动它。Git保护的是工程源码和文档，不是个人账目。账目应使用App内“完整备份”，并把备份复制到另一个安全位置。
