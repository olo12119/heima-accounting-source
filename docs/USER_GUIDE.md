# 黑马记账用户指南

## 如何体验当前1.3.0预览版

当前1.3.0功能已经完成代码开发、自动测试和免安装预览打包，但按照用户要求暂时没有制作新的Windows安装包。

唯一推荐方式：返回项目根目录，双击：

```text
00-点我打开黑马记账-当前最新版.cmd
```

它会打开 `可直接打开-黑马记账-1.3.0预览版` 中的程序，不需要安装，也不需要保持PowerShell窗口开启。整个免安装文件夹必须保留，不能只把里面的 `HeimaAccounting.exe` 单独复制出去。

只有免安装目录被清理时，启动按钮才会自动改用以下源码命令：

```powershell
npm.cmd run dev
```

源码方式需要保持PowerShell窗口打开；关闭黑马记账后再关闭PowerShell。两种方式读取相同的正式本地账本，首次体验重要数据前建议先导出完整备份。

## 如何打开

### 安装版

双击 `HeimaAccounting-Setup-1.1.0-x64.exe`，按安装向导完成安装，然后从桌面或开始菜单打开“黑马记账”。由于当前版本未购买代码签名证书，Windows 可能显示“未知发布者”。

这是旧1.1.0，不用于检查当前1.3.0功能。

### 便携版

直接双击 `HeimaAccounting-Portable-1.1.0-x64.exe`。便携指软件无需安装，但账目仍安全保存在 Windows 用户数据目录，不会跟着 EXE 四处移动。

这也是旧1.1.0。当前1.3.0使用根目录的唯一启动按钮。

## 如何记一笔

1. 点击右上角或首页绿色卡片中的“记一笔”。
2. 选择“支出”或“收入”，再输入金额，例如 `12.50`。
3. 选择该类型对应的一级分类和二级分类；可点击常用分类快速选择。
4. 如果没有合适分类，可在“一级分类”旁点击“新建”，或在“二级分类”旁点击“添加到当前分类”。保存分类后会自动选中，已输入的金额不会丢失。
5. 收入还可选择“退款”或“报销”，并关联原支出；这笔钱会在统计里抵扣原支出，不会当成新的赚钱收入。
6. 某笔账只想留档、不希望影响趋势和预算时，可勾选“不计入统计”。
7. 日期和时间默认是当前时间，可以修改；备注可不填，最多200字。
8. 点击“保存支出”或“保存收入”，也可以按 Enter。

## 如何修改或删除

- 首页可点击最近账目直接编辑。
- 在“账单”页，把鼠标移到某一笔上，点击铅笔按钮修改。
- 点击垃圾桶按钮后仍需点击“确认删除”；点击取消不会删除。

## 如何查看账单与统计

- “账单”页可切换今天、本周、本月、今年、全部或自定义日期，还可筛选全部收支、仅支出或仅收入；本周从周一开始。
- 搜索框可按备注、分类或金额找账。切换到“日历”，可以看到每天的收支；点击某一天会回到这一天的账单列表。
- “统计”页可切换今日、本周、本月、今年或自定义日期，再选择支出分析或收入分析，查看总额、与上一周期的差异、每日趋势、分类排行和占比。

## 如何设置预算和快捷模板

进入“预算与计划”：

1. 在“本月总预算”填写本月希望控制的总支出，也可以给餐饮、交通等一级分类单独填写上限。
2. 点击“保存预算”。预算只是提醒和进度展示，超出后仍然可以正常记账。
3. 经常重复的房租、工资、早餐等可以保存为模板。一次性模板随时点“记一笔”；周期模板可选择每周、每月或每年。
4. 周期模板到期只会显示待确认，不会在你不知道的情况下自动生成账目；点击“到期确认”后才真正入账。

## 如何管理自己的分类

1. 进入左侧“分类管理”，先选择“支出分类”或“收入分类”。
2. 点击“新增一级分类”，填写一级分类名称和第一个二级分类。
3. 选择一个立体3D分类图标和分类颜色，预览满意后保存。
4. 也可以在任意启用中的系统或自定义一级分类下点击“添加二级分类”。
5. 系统分类带锁标记，不能修改；自定义分类可以编辑、上下排序、停用或重新启用。
6. 删除自定义分类时，如果它没有被账目使用会直接删除；如果已有历史账目，App会改为安全停用，历史账单不会消失。

停用的分类不会出现在新记账表单中，但会继续显示在历史账单和分类管理页中。

## 如何更换颜色主题

进入“数据与设置”的“外观模式”：

1. 从黑曜鎏金、极光深海、琥珀日落、紫晶暮色中选择一种颜色主题。
2. 再选择浅色、深色或跟随系统。
3. 两项可以自由组合，点击后立即生效并自动保存。

## 如何导出 CSV

进入“数据与设置”，点击“导出 CSV 表格”旁的“导出”，选择保存位置。文件包含全部收入与支出，并有明确的“类型”列，使用 Excel 可识别的 UTF-8 中文格式。

## 如何导入 CSV

1. 进入“数据与设置”，点击“导入 CSV 账单”旁的“导入”。
2. 选择CSV文件。App会先告诉你可导入、无效和重复的数量；确认后才写入。
3. 导入前会自动备份当前账本，同一笔账重复导入会被跳过。

建议使用黑马记账自己导出的CSV，或至少准备“类型、金额、一级分类、二级分类、日期、时间、备注”等中文表头。无效日期、金额或找不到的分类会被跳过。CSV无法可靠保存“某笔退款关联哪笔原支出”这种关系，涉及退款/报销的完整迁移请使用完整备份。

## 如何备份

进入“数据与设置”，点击“导出完整备份”。第4版备份包含全部账目、自定义分类、主题、预算和模板。妥善保存 `.heima-backup.json` 文件，最好再复制到另一块磁盘或可信的个人存储设备。

## 如何恢复

1. 点击“从备份恢复”。
2. 阅读替换提示并确认。
3. 选择之前导出的完整备份。
4. App 会校验文件，并先自动保存当前账本，再用备份内容完整替换。

不要手工修改备份文件；修改后校验值不一致会被拒绝。恢复不是合并操作。

## 如何开启隐私密码

在“数据与设置”的“隐私密码”里输入4至12位数字并点击“开启密码”。关闭并重新打开App后，需要输入正确密码才能看到账本。密码只保存在本机，不会上网。

请务必记住密码。这个功能主要防止身边的人随手查看，不等同于给数据库文件做专业加密，也不能代替Windows账户密码和磁盘加密。

## 账目保存在哪里

Windows：

```text
%APPDATA%\HeimaAccounting\data\heima-accounting.sqlite3
```

macOS：

```text
~/Library/Application Support/HeimaAccounting/data/heima-accounting.sqlite3
```

恢复前自动备份位于同一 `HeimaAccounting` 目录下的 `backups` 文件夹。不要在 App 运行时手动移动、删除数据库或旁边的 `-wal`、`-shm` 文件。

## 网络与账号

日常使用完全不需要联网、注册或登录。黑马记账不会把账目上传到服务器。
