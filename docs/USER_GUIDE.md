# 黑马记账用户指南

## 如何体验当前1.2.0预览版

当前1.2.0功能已经完成代码开发和自动测试，但按照用户要求暂时没有制作新的Windows安装包。体验时在项目根目录打开PowerShell，执行：

```powershell
npm.cmd run dev
```

保持PowerShell窗口打开即可使用预览版；关闭黑马记账窗口后可以再关闭PowerShell。这个方式使用的仍是正式本地账本，首次体验重要数据前建议先在现有版本中导出完整备份。

## 如何打开

### 安装版

双击 `HeimaAccounting-Setup-1.1.0-x64.exe`，按安装向导完成安装，然后从桌面或开始菜单打开“黑马记账”。由于当前版本未购买代码签名证书，Windows 可能显示“未知发布者”。

### 便携版

直接双击 `HeimaAccounting-Portable-1.1.0-x64.exe`。便携指软件无需安装，但账目仍安全保存在 Windows 用户数据目录，不会跟着 EXE 四处移动。

## 如何记一笔

1. 点击右上角或首页绿色卡片中的“记一笔”。
2. 选择“支出”或“收入”，再输入金额，例如 `12.50`。
3. 选择该类型对应的一级分类和二级分类；可点击常用分类快速选择。
4. 日期和时间默认是当前时间，可以修改。
5. 备注可不填，最多200字。
6. 点击“保存支出”或“保存收入”，也可以按 Enter。

## 如何修改或删除

- 首页可点击最近账目直接编辑。
- 在“账单”页，把鼠标移到某一笔上，点击铅笔按钮修改。
- 点击垃圾桶按钮后仍需点击“确认删除”；点击取消不会删除。

## 如何查看账单与统计

- “账单”页可切换今天、本周、本月、全部，还可筛选全部收支、仅支出或仅收入；本周从周一开始。
- “统计”页可切换今日、本周、本月，再选择支出分析或收入分析，查看总额、每日趋势、分类排行和占比。

## 如何管理自己的分类

1. 进入左侧“分类管理”，先选择“支出分类”或“收入分类”。
2. 点击“新增一级分类”，填写一级分类名称和第一个二级分类。
3. 选择一个双色图标和分类颜色，预览满意后保存。
4. 也可以在任意启用中的系统或自定义一级分类下点击“添加二级分类”。
5. 系统分类带锁标记，不能修改；自定义分类可以编辑、上下排序、停用或重新启用。
6. 删除自定义分类时，如果它没有被账目使用会直接删除；如果已有历史账目，App会改为安全停用，历史账单不会消失。

停用的分类不会出现在新记账表单中，但会继续显示在历史账单和分类管理页中。

## 如何更换颜色主题

进入“数据与设置”的“外观模式”：

1. 从黑马墨绿、雾蓝海岸、暖杏琥珀、紫藤暮色中选择一种颜色主题。
2. 再选择浅色、深色或跟随系统。
3. 两项可以自由组合，点击后立即生效并自动保存。

## 如何导出 CSV

进入“数据与设置”，点击“导出 CSV 表格”旁的“导出”，选择保存位置。文件包含全部收入与支出，并有明确的“类型”列，使用 Excel 可识别的 UTF-8 中文格式。

## 如何备份

进入“数据与设置”，点击“导出完整备份”。第3版备份包含全部账目、自定义分类和主题设置。妥善保存 `.heima-backup.json` 文件，最好再复制到另一块磁盘或可信的个人存储设备。

## 如何恢复

1. 点击“从备份恢复”。
2. 阅读替换提示并确认。
3. 选择之前导出的完整备份。
4. App 会校验文件，并先自动保存当前账本，再用备份内容完整替换。

不要手工修改备份文件；修改后校验值不一致会被拒绝。恢复不是合并操作。

## 账目保存在哪里

Windows：

```text
%APPDATA%\HeimaAccounting\data\heima-accounting.sqlite3
```

macOS：

```text
~/Library/Application Support/HeimaAccounting/data/heima-accounting.sqlite3
```

恢复前自动备份位于同一 `HeimaAccounting` 目录下的 `backups` 文件夹。不要在 App 运行时手动移动、删除数据库或旁边的 `-wal`、`-shm` 文件。

## 网络与账号

日常使用完全不需要联网、注册或登录。黑马记账不会把账目上传到服务器。
