## 真实失败、根因与修复

1. ❌ 第一次定向手势测试写错类名，测试框架报告找不到类；改为真实类 `NavigationAndRecordTest` 后测试通过。这不是 App 功能失败。
2. ❌ 模拟器遗留旧 `.dev.test` 签名导致完整门禁在执行 0 项测试时停止；仅卸载模拟器测试外壳后，从头执行 38/38 通过。
3. ❌ 首次正式签名未给 `apksigner` 进程设置 `JAVA_HOME`；明确使用 D 盘 JDK 后签名和验签成功，失败生成的未签名文件没有交付。
4. ❌ `aapt` 不支持当前中文路径并误报找不到 Manifest；将同一 APK 临时复制到英文路径后确认包名、版本号和 SDK 信息正确。
5. ❌ 人工视觉检查发现分类编辑器背景文字穿透；改为复用统一模态框架的 Dim 与高可读内容层后重新截图，问题消失。
6. ⚠️ Lint 曾给出 1 条 Long 状态装箱性能提示；改为 `mutableLongStateOf`，最终 Lint 为 0 issue。
