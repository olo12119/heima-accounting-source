## 二、四期（动效 + UI 大胆创新）

### 4.0 设计语言基线 —— 先修"Liquid Glass 不像玻璃"的老问题

> 本节融合两份专业设计规范（SuperDesign 现代 UI 方法论 + 毛玻璃 Glassmorphism 三大支柱），
> 核心结论：**你现在的 App 是"半透明平板"，不是"液态玻璃"**。毛玻璃的灵魂是"底层有鲜艳色彩让玻璃去透、去折"；你底层氛围光斑太淡（alpha 仅 0.12~0.62），玻璃"无光可折"，于是看起来就是一片灰白。

#### 4.0A 诊断：为什么现在不像 Liquid Glass

| 问题 | 现状（已核对源码） | 规范要求 | 怎么改 |
|------|------------------|---------|--------|
| 背景不够艳 | `AmbientBackdrop` 3 个氛围光斑 alpha 0.12~0.62，几乎纯色 | 毛玻璃底层必须鲜艳丰富（渐变/彩色光斑），否则"无光可透" | 光斑 alpha 提到 0.35~0.85 并提高饱和度；再加 1~2 个更大更亮的大色斑 + 一条更明显的彩带，让玻璃"折射"出颜色 |
| 模糊缺饱和增强 | 只 `blur()`，无 `saturate()` | 标准写法 `blur(10px) saturate(180%)`，透出的颜色更鲜活 | 模糊链路显式叠加饱和增强（kyant `vibrancy`/`lens` 之上再叠 `saturate`） |
| 面板半透明但"平" | 半透明渐变叠在素底色上，读作"灰白片" | 三件套缺一不可：10~30% 半透明 + 微光边框 + 柔和长影 | 微光边框 alpha 0.2~0.3；阴影改 `8dp 扩散32%` 柔和长影 |
| 高光/折射太弱 | rim 高光 alpha 0.14~0.24、sheen 0.025 | 玻璃要有清晰"镜面高光"：顶部一条亮边 + 内发光 | 顶部高光线 alpha 提到 0.5~0.6；面板内加极淡 inner glow |
| 图标太素 | 分类图标单色扁平 | 面板内图标用鲜艳渐变，与半透明面板形成对比 | 分类图标改同色族渐变填充 + 顶部微高光 |
| 层次太近 | 背景/卡片/浮层明度差小，卡片间距 <24dp | 至少 3 层纵深、面板间距 ≥24dp | 三层明度进一步拉开；卡片间距统一 ≥24dp 体现悬浮 |

#### 4.0B 设计语言六原则（SuperDesign × 毛玻璃 融合）

1. **玻璃三件套**：半透明填充(10~30%) + 背景模糊(带饱和增强) + 微光边框(白 0.2~0.3)，三者缺一不可。
2. **底色要艳**：底层氛围光斑是玻璃的灵魂，必须够艳够亮；它是"玻璃反光"的来源，不是装饰。
3. **节奏**：过渡用 spring（damping 0.82~0.88），时长 150~400ms ease-out；按压 100~150ms；页面切换 300~400ms。
4. **层次**：每个动作至少 2 层叠加（位移+透明度 / 缩放+模糊）；文字层级用**透明度而非字号**表达。
5. **响应**：按下 scale 0.97 + 弹性回弹；所有可点元素 hover/active 都要有反馈；触控目标 ≥44×44。
6. **克制**：阴影最多 2 层、避免重阴影；避免"通用蓝"；大圆角(16~24dp)软化玻璃硬边。

> 落地优先级：4.0A 的"背景变艳 + 模糊加饱和 + 高光加强"是让 App 立刻有"玻璃感"的关键三步，排在四期所有页面动效之前。

### 4.1 五大页面的创新方案

#### 📱 页 1 · 首页

| 区域 | 现在的问题 | 创新方案 |
|------|----------|---------|
| HERO 消费/收入/结余 | 大数字直接显示，无质感 | **数字滚动动画**：从 0 数到当前值（180ms spring，金额每跳一档有微"咔哒"感）；结余正/负用颜色 morph（不是切换）+ 数字短暂放大 1.08 回弹 |
| 日期问候 | 静态文字 | 每天首次打开时，日期/问候字有"逐字淡入"（stagger 30ms），底部有一道极淡的辉光从左扫到右（1.2s） |
| 本月趋势卡片 | 视觉单调 | **重做图表外壳**：卡片四角加柔和内发光；切换图表时，旧图"散成粒子"（0.3s 渐隐+ 微粒向上飘散）→ 新图"粒子聚合"成图（0.4s 落入） |
| 财务状态卡片 | 单一句话 | 升级为**财务体检卡**：3~4 行小指标（结余率 / 预算节奏 / 同比），每行带迷你进度条，进度条从 0 长到目标值；指标间有 60ms stagger |
| 最近账单列表 | 直接列出 | **逐条交错入场**（每条延迟 40ms 滑入）；左滑出现"删除"按钮（spring 回弹），删除时该条向左飞出 + 透明度归 0，下方条目顺势顶上来 |
| 下拉刷新 | 没做 | **自定义下拉头**：拉下到一定距离，松手后顶部出现圆环进度 + 品牌色光弧；完成时一个"✓"勾画出来（SVG 描边动画） |

#### 📊 页 2 · 统计

| 区域 | 现在的问题 | 创新方案 |
|------|----------|---------|

| 支出总额 | 大数字直接显示 | **数字滚动 + 千分位动画**：从 0 数到目标，按千分位分组逐组跳入 |

| 所选分类账单 | 静态卡片列表 | 选中环形分类后，**环形切片向外推 4dp，下方账单列表逐条 stagger 飞入**（每条从右侧 30% 偏移 + 透明度 0 → 原位） |

### 4.2 通用创新（跨页面复用）

| 能力 | 描述 |
|------|------|

### 4.3 图表美学大改造

## 三、实施分期建议

四期工作量大且敢创新，拆成两小期：

| 阶段 | 内容 | 预计工时 |
|------|------|---------|
| **二期补丁** | 加回触觉/音效开关 | 半天 |
| **三期 3.1** | 滑动跟手性能 | 1 天 |
| **三期 3.2** | 财务分析增强 | 1.5 天 |
| **三期 3.3** | 预算重做三模式 | 2 天 |
| **四期 0（玻璃质感修复）** | 4.0A 三步：背景变艳(氛围光斑 alpha↑+饱和↑) + 模糊加饱和增强 + 高光/微光边框加强 + 图标渐变 — 让 App 立刻有"玻璃感" | 1 天 |
| **四期 A（动效基础）** | 数字滚动/按下物理/stagger 入场/成功气泡 — 通用基础设施 | 1.5 天 |
| **四期 B（页面动效）** | 五大页面各自的创新动效 | 3 天 |
| **四期 C（图表美学）** | 折线/柱状/饼图大改造 + 渐变填充 | 1.5 天 |

> 建议执行顺序：**二期补丁 → 三期(3.1→3.2→3.3) → 四期 0（玻璃质感，最关键）→ 四期 A→B→C→D**。
> 四期 0 虽排在三期后，但它见效最快，如果想让 App"先变好看"，可把四期 0 提到三期之前。
