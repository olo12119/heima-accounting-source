# Android产品定位与范围

## 一句话定位

黑马记账是一款年轻、高级、具有收藏感的Android个人财务管理App。它用几秒钟完成一笔收入或支出记录，通过清楚的预算、趋势和分类洞察帮助用户理解自己的钱，同时保持本地优先、无需登录和不打扰。

## 设计目标

- 第一眼具有精品应用的完成度，不像后台系统或网页套壳。
- 简洁但不简陋：减少同时出现的信息，不删除必要能力。
- 用材质、留白、字号、层级和动效形成视觉特色，而不是只换颜色。
- 主题具有完整世界观，用户可以按心情切换。
- 尊重Android操作习惯，同时借鉴iCost的信息组织和Apple设计的克制感。
- 日常核心操作能单手完成，常见记账流程控制在少量步骤内。

## 目标用户

- 主要用户是产品负责人本人及身边朋友。
- 默认使用人民币和简体中文。
- 用户不应被要求理解会计术语、数据库或同步机制。
- 用户可能使用不同品牌、尺寸和性能的Android手机。

## 核心价值排序

1. 快速记账：任何主页面都能立即打开记账面板。
2. 看清现状：首页先回答今天花了多少、本月趋势和预算还剩多少。
3. 数据可信：金额按整数分保存，恢复和迁移必须校验并可回滚。
4. 长期愿意使用：主题、字体和适量动效带来收藏感与新鲜感。
5. 本地安心：第一版不依赖账号、广告或云端服务。

## 1.0 正式版能力

- 收入、支出、两级分类、自定义分类和常用分类。
- 账单列表、新增、编辑、删除与撤销。
- 今日、本周、本月、今年与自定义单日/区间统计，包含收支结构、趋势和分类排行。
- 月度总预算、剩余金额和超预算提示。
- CSV 导出与完整 JSON 备份恢复。
- 澄澈蓝、自然治愈两套主题，跨主题共用的 Liquid Glass 材质。
- 浅色、深色、跟随系统、金额隐私、操作音效、触觉和减少动效。
- 点击、页面横滑和底部 Lens 拖动三种导航方式；记账始终是独立主操作。

## 第一版明确不做

- iOS、iPadOS、macOS或Apple Watch应用。
- 用户账号、广告、在线会员和社交系统。
- 银行卡、支付宝或微信自动抓取。
- 企业审批、发票、报税或投资行情。
- 在线主题购买和在线字体下载。
- 未经用户确认的周期账单自动入账。
- 退款关联、报销冲减、快捷模板、周期模板和本地隐私密码。
- 云同步、多人共享、银行/支付宝/微信自动抓取。

## 财务健康状态

首页的财务健康状态不是信用评分，也不提供投资建议。它只使用用户看得懂的本地规则：

- 本月预算使用比例与时间进度是否匹配。
- 本月普通收入减去有效支出的差额。
- 最近七天与前七天的支出变化。
- 是否出现分类预算接近上限或已经超支。

状态只使用“平稳、需要留意、接近预算、已经超支”等中性语言，并允许点击查看计算依据，避免制造焦虑或假装提供专业理财结论。

## 成功指标

- 从点击中央记账按钮到保存普通账目，熟练用户可以快速完成。
- 首页无需滚动太远即可看到今日消费、本月趋势、预算和最近账单。
- 两套主题不改变关键操作位置，切换后无需重新学习。
- 字体放大、降低透明度或减少动画后仍能完成全部核心操作。
- Android 完整备份恢复后，账目笔数、分类关系和金额合计一致。
