## 一、项目信息

- **项目名称**：heima_accounting（黑马记账）
- **技术栈**：Android / Kotlin / Jetpack Compose / Material Design 3，中文 UI，金额以"分"为单位存储
- **源码根目录**：`d:\work\heimajizhang\heima-accounting-source`
- **原始需求复述**：前三期已交付，但 App 的"Liquid Glass"目前只是"半透明平板"，不像玻璃；页面动效偏单调，图表与图标配色偏素。用户拍板"敢于创新、求质感、不堆功能"，四期按豪华版全量落地：先把玻璃质感修到位（背景变艳、模糊加饱和、高光加强），再给五大页面加整套动效、做通用动效组件、大改图表美学、拓展音效，并确保动效可降级、深色模式观感不退化。

---

## 二、产品目标

让黑马记账从"能用"跃升到"好看、好用、有质感"：玻璃真正像玻璃（底层鲜艳、模糊带饱和、有镜面高光和微光边框）；五个页面每个操作都有符合物理直觉的动效反馈，但绝不喧宾夺主、绝不拖慢性能；图表与图标告别"单色扁平"；音效触觉补齐键盘与图表反馈；所有动效都尊重"减少动态效果"设置，深浅色下观感一致不退化。

## 三、用户故事

1. **玻璃质感**：作为一个每天打开 App 的用户，我希望界面的玻璃卡片看起来真的像"液态玻璃"（透出鲜艳的底层光、有柔和镜面高光和微光描边），而不是灰白平板，以便第一眼就觉得"精致"。
2. **首页动效**：作为一个每天先看首页的用户，我希望金额数字滚动、趋势图切换有粒子感、账单逐条滑入、左滑就能删除，以便操作有反馈、看数据不单调。
3. **统计动效**：作为一个查看统计的用户，我希望切时段有过渡、排行金银铜有竞速感、主导分类一眼可见，以便更快读懂钱花在哪。
4. **预算动效**：作为一个用预算控制开销的用户，我希望进度条像"能量液"、储蓄进度有水流感、超支时数字晃动提醒，以便预算状态一目了然且超支有警醒。
5. **记账动效**：作为一个高频记账的用户，我希望记账弹层弹出有弹性、按数字有回弹、保存成功有气泡反馈，以便记账过程顺手又有仪式感。
6. **音效拓展**：作为一个对反馈敏感的用户，我希望按数字键有极轻"咔"、图表切换有极短"嗡"、首次记账有成功琶音，以便每次操作都有恰到好处的听觉反馈。
7. **降级与深色兼容**：作为一个开了"减少动态效果"或深色模式的用户，我希望动画变少但不缺失、深色下观感一样精致，以便任何时候使用都不受影响。

## 四、需求池（全部 P0，本期必做）

### 需求 1 · 玻璃质感修复（Liquid Glass 真正像玻璃）

**验收标准：**

- A1. 背景氛围光斑 alpha 由现状 0.12~0.62 提升到 0.35~0.85，且饱和度提升，肉眼可辨"背景更鲜艳"；新增 1~2 个更大更亮的大色斑（+1 条明显彩带），底层不再是"几乎纯色"。
- A2. 模糊链路显式叠加饱和增强，等效 `blur + saturate(180%)`：玻璃透出的背景颜色比改前更鲜活（截图对比肉眼可辨），不再只有 blur。
- A3. 面板半透明填充在 10%~30% 之间，且三件套齐备——半透明填充 + 微光边框 + 柔和长影，缺一不可（逐卡核对）。
- A4. 微光边框 alpha 提升到 0.2~0.3（白），卡片边缘在浅色与深色下均"看得见"；顶部高光线 alpha 提升到 0.5~0.6，形成清晰"镜面高光"亮边。
- A5. 阴影改为 8dp / 32% 扩散的柔和长影，且阴影最多 1~2 层、避免重阴影；卡片浮起感在深色模式下也"看得见不刺眼"。
- A6. 面板间距统一 ≥24dp，圆角 16~24dp；整体至少 3 层纵深（背景 / 卡片 / 浮起卡片）肉眼可辨。
- A7. 分类图标由单色扁平改为同色族渐变填充 + 顶部微高光，与半透明面板形成对比（肉眼可辨渐变，而非纯色块）。
- A8. 文字层级用"透明度"而非"字号"表达主次，正文对比度 ≥4.5:1；浅色与深色模式均达标。
- A9. 玻璃质感修复在"减少动态效果"开启时不受影响（静态观感一致，仅动画被降级）。
- A10. 关闭"Liquid Glass"开关后，上述玻璃效果正确退化为普通卡片（沿用三期补丁能力），开关语义不变。

### 需求 2 · 五大页面动效（豪华版全做）

**验收标准：**

**首页：**

- B1. HERO 大数字（消费/收入/结余）有滚动动画：从 0 数到当前值，时长 180ms spring，金额每跳一档有微"咔哒"感；结余正负切换用颜色 morph（平滑过渡，非瞬间变色）+ 数字短暂放大 1.08 再回弹。
- B2. 每天首次打开首页时，日期/问候文字逐字淡入（stagger 30ms），底部有一道极淡辉光从左扫到右（1.2s）。
- B3. 趋势图切换时：旧图"散成粒子"（0.3s 渐隐 + 微粒向上飘散）→ 新图"粒子聚合"成图（0.4s 落入），肉眼可辨粒子过渡而非闪切。
- B4. 财务体检卡（三期已有多指标）升级为指标行 stagger 入场：每行进度条从 0 长到目标值，指标间 60ms stagger。
- B5. 最近账单列表逐条交错入场（每条延迟 40ms 滑入）；左滑出现"删除"按钮（spring 回弹），删除时该条向左飞出 + 透明度归 0，下方条目顺势顶上。
- B6. 新增自定义下拉刷新：拉到阈值松手后顶部出现圆环进度 + 品牌色光弧，完成后"✓"以 SVG 描边动画勾出。

**统计页：**

- B7. 顶部时段切换做共享元素过渡（金额数字从旧位置飞到新位置），环形/柱图用 `AnimatedContent` + 12° 轻微旋转入场。
- B8. 支出总额数字滚动 + 千分位动画（从 0 数到目标，按千分位分组逐组跳入）。
- B9. 收支结构环形图：当某分类占比 >85% 时，主导切片向外滑出 4dp 并加一圈淡发光，中心数字加副标"占比 96%"（更小字）；次要切片用同色族渐变填充。

- B11. 分类排行前三名分别加金/银/铜金属感渐变；条形"竞速"动画（同时开始、按比例速度生长、120ms 内全部到位）；第一名右上有皇冠 emoji 飘入 + spring 落下。
- B12. 选中环形分类后，该切片向外推 4dp，下方账单列表逐条 stagger 飞入（每条从右侧 30% 偏移 + 透明度 0 → 原位）。

**预算页：**

- B13. 顶部 Gauge 改双层：底层浅灰满弧 + 上层深色进度弧；进度弧增长有"能量液"效果（头部圆点带微小粒子拖尾）；>85% 弧线变橙 + 轻微脉动；>100% 弧线变红 + 圆点处"震动"一下。

### 需求 3 · 通用动效组件（跨页面复用）

**验收标准：**

- C1. `AnimatedAmount(value, duration=180ms)` 数字滚动计数器：任意金额/百分比从 0 滚到目标值，spring 弹性，复用后可被任意页面调用。
- C2. 共享元素过渡：基于 `SharedTransitionLayout` 实现，统计页切时段时金额数字"飞"到新位置，过渡流畅无闪跳。
- C3. Stagger 入场：`AnimatedVisibility + delays` 封装，每项 40~60ms 延迟，可用于列表/卡片入场。
- C4. `Modifier.pressable()` 按下物理：scale 0.97 + 弹性回弹，60~90ms，所有可点元素均有按下反馈；触控目标 ≥44×44dp。
- C5. 滚动视差：Ambient 背景随滚动轻微反向位移（≤6px），营造深度，不造成明显性能损失。
- C6. 成功气泡：全局 Snackbar 替代品——底部圆形气泡上浮 + ✓ 勾画 + 自动淡出。
- C7. 通用组件在浅色与深色模式下观感一致，且尊重"减少动态效果"（降级为简单淡入淡出或无动画）。

### 需求 4 · 图表美学大改造

**验收标准：**

- D1. 所有图表填充从纯色改为同色族渐变（顶部亮→底部暗），肉眼可辨渐变，不再单色。
- D2. 饼图主导切片：某分类 >85% 时切片向外推 4dp + 一圈淡发光；中心副标显示占比（更小字）；次要切片同色族 alpha 渐变填充。
- D3. 柱状图前三名加金/银/铜金属渐变，其余柱用同色族渐变。
- D4. 折线连续 0 天用虚线绘制，最后一个有数据的点实线 + 粒子拖尾；面积径向渐变（中心透明→边缘 12%）。
- D5. 统计页有效数据点 ≤2 个时，自动切换到"日记式"——每条记录是一张小卡片，按天分组展示。
- D6. 图表配色避免"通用蓝"，与品牌主色体系一致；深色模式下图表配色同步调亮，肉眼可辨且不刺眼。
- D7. 图表切换/加载动画均尊重"减少动态效果"（开启后动画简化，仍能正确显示数据）。

### 需求 5 · 音效拓展

**验收标准：**

- E1. 数字键盘按键：极轻"咔"声（短促）+ 轻 tick，响度轻柔（延续三期 −18~−24dB 量级）。
- E2. Tab / 图表切换：一声极短"嗡"（40ms）+ 中等 tick。
- E3. 数字滚动到位：一声"叮"（比保存音更短）。
- E4. 预算超额瞬间：一声低沉闷响 + 长振一档。
- E5. 首次记账成功：一次"成功琶音"（C5→E5→G5 上行，比普通保存音更丰富）。
- E6. 里程碑音效（如第 100 笔庆祝）**不做**——不出现任何相关音效。
- E7. 所有新音效延续二期 v2 合成规范：有泛音、快速起音 + 指数衰减、微失谐、同一音色家族；不使用纯单频正弦波。
- E8. 关闭"操作音效"后上述所有声音消失；关闭"触觉反馈"后上述所有振动消失（延续三期补丁开关语义）。
- E9. 快速连按键盘不出现声音叠爆、破音或卡顿。

### 需求 6 · 动效降级 + 深色模式兼容

**验收标准：**

- F1. 所有动效读取"减少动态效果"（reduceMotion）开关：开启后动画降级为简单淡入淡出或直接显示终态，不出现大幅位移/旋转/粒子等动效。
- F2. 降级模式下功能完整可用（记账、看统计、设预算、删账单等核心操作不受影响），只是"动效变少"。
- F3. 所有新增动效与玻璃效果在深色模式下观感不退化：文字对比度 ≥4.5:1、卡片三层纵深可辨、高光/描边/阴影"看得见不刺眼"。
- F4. 深浅色模式切换时，动效与配色平滑过渡，不闪白、不闪烁。
- F5. 动效增加后，快速滑动首页与列表仍满足三期性能基线（不掉帧、跟手），动效不得拖慢滚动。
- F6. 关闭"Liquid Glass"开关后，五大页面动效仍正常（动效不依赖玻璃效果），无残留玻璃渲染。

## 五、UI / 交互要点（设计方向）

### 玻璃质感（需求 1）

- **三大支柱缺一不可**：半透明填充（10~30%）+ 背景模糊（带 saturate 180%）+ 微光边框（白 0.2~0.3）。
- **底层要艳**：氛围光斑是玻璃"反光"的来源，不是装饰。光斑 alpha 提到 0.35~0.85、提高饱和度、加 1~2 个大色斑 + 明显彩带，让玻璃"有光可透"。
- **镜面高光**：面板顶部一条亮边（alpha 0.5~0.6）+ 面板内极淡 inner glow，营造"玻璃折射"感。
- **纵深节奏**：背景 / 卡片 / 浮起卡片三层明度拉开；卡片间距 ≥24dp；圆角 16~24dp；阴影 8dp 32% 柔和长影、最多 1~2 层。
- **图标**：分类图标同色族渐变填充 + 顶部微高光，与半透明面板形成对比。

### 动效节奏（需求 2/3，SuperDesign 标准）

- 过渡 150~400ms ease-out；按压 100~150ms；页面切换 300~400ms。
- 微语法示例：按钮按下 150ms [scale 1→0.95→1]；fadeIn 400ms ease-out [Y+20→0, α0→1]；bounce 600ms [S0.95→1.05→1]。
- 每个动作至少 2 层叠加（位移+透明度 / 缩放+模糊）；文字层级用透明度而非字号。
- 按下 scale 0.97 + 弹性回弹；所有可点元素有 hover/active 反馈；触控目标 ≥44×44。
- 克制：阴影最多 1~2 层、避免重阴影；避免"通用蓝"；大圆角软化玻璃硬边。

### 五大页面动效（需求 2）

> 逐条对应需求池 B1~B25，此处仅补实现要点，验收以需求池为准。

- 首页 HERO 数字滚动复用 `AnimatedAmount(180ms spring)`；趋势图粒子过渡需在"减少动态效果"下退化为淡入淡出。
- 统计页共享元素过渡用 `SharedTransitionLayout`；环形图主导切片外推仅当占比 >85% 触发。
- 预算页双层 Gauge 能量液头部圆点带粒子拖尾；三联胶囊选中用流体填充（高亮流入）。
- 记账弹层背景模糊 0.3s + 面板 spring 380ms；保存成功光带→飞出→气泡三段式。
- 我的页头像呼吸 4s 周期、视差 ≤0.4px/px；主题迷你预览做成缩小版首页骨架。

### 通用组件（需求 3）

- 全部封装为可复用 Composable：`AnimatedAmount` / 共享元素过渡 / Stagger 入场 / `Modifier.pressable` / 滚动视差 / 成功气泡。
- 组件默认读 reduceMotion 降级。

### 图表美学（需求 4）

- 渐变填充方向统一"顶部亮→底部暗"，符合玻璃"光线"。
