# Android 构建、测试与APK说明

## 给普通用户

你不需要阅读源码或手工输入本页命令。现在推荐在电脑上双击：

`00-用Android Studio查看手机版.cmd`

它会直接打开手机工程。也可以把下面的APK复制到真机安装：

`手机安装包/黑马记账-Android-视觉修正版-0.2.0.apk`

请按同文件夹内的 `手机安装说明.txt` 操作。

## 一键构建入口

开发者可以双击：

`apps/android/构建并检查视觉体验版.cmd`

脚本会临时建立纯英文盘符，设置D盘工具路径，依次执行APK构建、11项单元测试和严格Lint，再把成功产物复制到 `手机安装包`。失败时不会复制一个假成品。

等价的核心Gradle任务是：

```text
:app:assembleDebug
:app:testDebugUnitTest
:app:lintDebug
```

## 性能与耗电现状

本阶段已经实现的保护：

- 只在底部导航、记账面板和重点卡片使用局部背景模糊；Android 12及以上使用Haze 1.7.2提供真实背景采样，旧设备和省电设置使用更实的半透明表面回退。
- 没有无限循环动画、后台服务、网络轮询或定时任务。
- 页面过渡主要使用位移、透明度和缩放，并遵守“减少动态效果”。
- 手机进入系统省电模式时，自动关闭高光装饰并提高表面不透明度。
- 用户可在“我的 → 动效与耗电”选择自动、精美或省电。
- 首页背景绘制使用Compose绘制缓存，静止时不会持续重画。

当前没有连接用户手机，因此尚未完成真实帧率、发热和电量消耗测量。该项不能用电脑编译替代；等功能数据阶段完成后，再通过用户授权的临时USB调试执行Macrobenchmark、帧耗时和Batterystats测试。
