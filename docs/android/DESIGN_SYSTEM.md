# Android Design System与组件库

## 设计原则

1. 内容先于装饰：用户先看懂金额、趋势和预算，再感受材质。
2. 少而有层级：同一屏幕最多只有一个最高视觉焦点。
3. 高级材质有限使用：玻璃属于操作层，普通内容保持清楚稳定。
4. 主题改变气质，不改变功能位置和数据含义。
5. Android原生习惯优先：返回、输入法、字体缩放、触觉和手势必须自然。

## 设备基准与自适应

- 主要设计画布：360×800dp和412×915dp。
- 小屏验证：320dp宽度，确保文字不重叠。
- 大屏与折叠屏：内容最大宽度受控，不把卡片无限拉宽；后续可采用双栏支持面板。
- 竖屏优先，但不能依赖固定像素高度。
- 使用系统安全区域，避开刘海、状态栏、底部手势条和显示挖孔。

## 空间系统

以4dp为最小单位、8dp为主要节奏：

| 用途 | 建议值 |
| --- | --- |
| 页面左右留白 | 20或24dp |
| 主区块间距 | 28至36dp |
| 卡片间距 | 16至20dp |
| 卡片内边距 | 18至24dp |
| 标题与说明 | 8至12dp |
| 紧密图标与文字 | 6至8dp |
| 最小触摸区域 | 48×48dp |

## 圆角层级

- 8dp：小标签和微型状态。
- 12至16dp：输入框、分段控件和小按钮。
- 20至24dp：普通内容卡片。
- 26至32dp：主财务卡和主题预览。
- 28至36dp：底部弹窗顶部圆角。
- 胶囊：Tab选中态、快捷筛选和悬浮操作。

圆角随主题允许轻微变化，但不能让相同组件在同一主题中无规律变化。

## 语义颜色

页面不直接写死某个绿色或蓝色，而使用语义名称：

- `backgroundBase`：页面背景。
- `surfacePrimary`：主要实体卡片。
- `surfaceSecondary`：次级区域。
- `glassControl`：高级玻璃操作层。
- `textPrimary`、`textSecondary`、`textTertiary`：三级文字。
- `brandPrimary`、`brandAccent`：品牌主色与少量强调色。
- `income`：收入。
- `expense`：支出。
- `warning`：接近预算。
- `danger`：超支或危险操作。
- `success`：保存、恢复完成。
- `outline`、`divider`：边界与分隔。

收入与支出不能只依赖颜色区分，还需使用正负号、方向图标或文字，照顾色觉差异。

## 字体层级

| 层级 | 字号建议 | 用途 |
| --- | --- | --- |
| Display Amount | 44至56sp | 今日消费、结余、预算剩余 |
| Page Title | 30至34sp | 页面主标题 |
| Section Title | 22至26sp | 主要内容区标题 |
| Card Title | 18至20sp | 卡片标题 |
| Body | 15至17sp | 账单与说明正文 |
| Label | 13至15sp | 按钮和标签 |
| Caption | 12至13sp | 时间与辅助信息 |

- 金额使用支持表格数字的字型，滚动时宽度稳定。
- 正文行高为字号的1.45至1.6倍。
- 标题最多两行；关键金额不截断，可在极端情况下自适应缩小。
- 必须测试系统字体100%、130%、160%和200%缩放。

## 材质层级

### 背景层

主题背景、柔和渐变、纸张纹理或环境光。它提供氛围，不承担按钮职责。

### 内容层

账单、分类和普通统计使用实体或标准磨砂卡片，保证长时间阅读稳定。

### 高级操作层

底部Tab Bar、中央记账按钮、筛选器和激活中的滑块使用Liquid Glass。玻璃应允许背景少量透过，并保持文字对比度。

### 临时浮层

记账面板、确认弹窗、主题预览和日期选择器可以使用更明显的动态模糊、折射与空间阴影。

## Liquid Glass参数方向

- 模糊半径根据设备能力分档，不以固定高值覆盖全屏。
- 表面透明度随背景明暗自适应。
- 使用1dp左右的内高光和低对比边框表达厚度。
- 折射仅在边缘和触摸区域发生，不持续扭曲文字。
- 玻璃下方内容移动时保持可读性；降低透明度后切换为实体表面。
- 阴影宽而轻，不使用黑色硬边。

## 图标体系

- 操作图标使用统一描边粗细的Android矢量图标。
- 分类图标可使用精致3D或主题专属插画，但轮廓和占位尺寸一致。
- 同一操作不能在不同页面使用不同含义图标。
- 图标旁优先保留文字，尤其是记账、删除、恢复和备份。

## 核心组件库

### 导航与框架

- `AppScaffold`：状态栏、安全区、页面背景和滚动框架。
- `GlassTabBar`：五项底部导航。
- `CentralRecordAction`：中央记账按钮。
- `TopSummaryBar`：月份、隐私遮挡和账本状态。

### 首页与数据

- `TodaySpendHero`：今日主金额和辅助指标。
- `HealthStatusChip`：可解释财务健康状态。
- `BudgetRemainCard`：预算剩余和时间进度。
- `CategorySpendCard`：分类金额、占比和主题图标。
- `MiniTrendChart`：七日趋势。
- `TransactionRow`：最近账单行。

### 记账

- `RecordBottomSheet`：可分阶段展开的记账面板。
- `EntryTypeSelector`：收入、支出和高级类型。
- `RollingAmountDisplay`：滚动金额显示。
- `FinanceKeypad`：自定义数字键盘。
- `CategoryCarousel`：常用与一级分类。
- `SecondaryCategoryPicker`：二级分类。
- `AdvancedEntrySection`：日期、备注、退款和排除统计。

### 统计与预算

- `PeriodSwitcher`：日期范围。
- `TrendChartCard`：趋势图。
- `CategoryDonut`：分类占比。
- `CategoryRanking`：分类排行。
- `BudgetGauge`：预算仪表。
- `BudgetCategoryRow`：分类预算。

### 个性化与系统

- `ThemePreviewCard`：主题动态预览。
- `FontPreviewCard`：字体实时样张。
- `AdaptiveDialog`：确认和错误弹窗。
- `SuccessEffect`：按主题变化的成功反馈。
- `EmptyState`、`LoadingState`、`ErrorState`：完整页面状态。

## 组件状态

每个可交互组件必须定义：

- 默认。
- 按下。
- 选中。
- 禁用。
- 加载。
- 错误。
- 降低透明度。
- 减少动画。
- 深色模式。
- 大字体。

## 无障碍与可读性

- 普通文字与背景保持足够对比度，玻璃不能让文字忽明忽暗。
- 所有图标按钮提供中文无障碍名称。
- 图表同时提供文字摘要，不能只靠颜色或图形表达。
- 成功粒子不能阻挡读屏提示。
- 焦点顺序与视觉顺序一致。
- 触觉反馈可关闭，动画强度可调。
