## 二、产品目标

让 App 在日常重度使用中"顺滑、聪明、可信"：快速滑动不再掉帧；财务状态不再只是一句"收支平稳"，而是让用户一眼看懂自己存下多少钱、钱花在哪儿、比上月好还是坏；预算支持"先存后花 / 整月上限 / 分类预算"三种真实理财习惯，老用户升级后数据一分不丢；同时把用户最在意的三个体验开关还给他们自己控制。

## 三、用户故事

1. **设置开关**：作为一个有个人偏好的用户，我希望设置页里能自己开关"操作音效""触觉反馈""Liquid Glass"，以便在安静场合关声音、在省心时全部打开，但"视觉质量"仍然不用我操心（默认最好）。
2. **滑动跟手**：作为一个每天快速翻账单的用户，我希望首页和账单列表快速滑动时流畅跟手、不掉帧，以便找账单不烦躁。
3. **财务体检**：作为一个想改善财务状况的用户，我希望首页直接告诉我"结余率多少、支出是否太集中、储蓄目标完成多少、比上月好还是坏"，以便不用自己算就能知道该不该省钱。
4. **统计小结**：作为一个查看统计的用户，我希望统计页顶部有一段用大白话写的财务小结，以便快速抓住本月的重点问题。
5. **先存后花**：作为一个"发工资先存一笔"的用户，我希望只设一个每月储蓄目标，App 自动算出本月可花额度并在我快花超时提醒我，以便守住储蓄计划。
6. **分类预算**：作为一个想控制某几个分类花销的用户，我希望给餐饮、购物等每个分类单独设额度并看到各自的进度，以便精准控制最容易超支的地方。
7. **老数据不丢**：作为一个老用户，我希望升级后原来的预算数字还在、能正常用，以便不用担心数据丢失。

## 四、需求池（全部为 P0，本期必做）

> 本期 4 项需求全部 P0。四期内容不列入本需求池。

### 需求 1 · 二期补丁：加回触觉 / 音效 / Liquid Glass 三个开关

**验收标准：**

- A1. 设置页"体验设置"区出现三个 toggle："操作音效""触觉反馈""Liquid Glass"；不出现"视觉质量"开关（逐条肉眼核对）。
- A2. 关闭"操作音效"后，保存成功、删除、撤销等所有操作声音全部消失；重新开启后恢复。
- A3. 关闭"触觉反馈"后，所有振动反馈消失；重新开启后恢复。
- A4. 关闭"Liquid Glass"后，卡片玻璃效果关闭（退化为普通底色卡片）；重新开启后恢复；切换时 App 不崩溃、不白屏。
- A5. 三个开关的状态跨 App 重启保持（杀掉 App 重开验证）。
- A6. 老版本 SharedPreferences 中已有的 soundEnabled / hapticEnabled / liquidGlassEnabled 记录升级后被正确读取，不出现"开关状态凭空重置"。
- A7. 开关关闭"操作音效"或"触觉反馈"后，另一项（振动/声音）不受影响，仍正常工作。
- A8. 省电 / 过热时的画质静默降级行为不变，且依然不弹出任何提示文案。

### 需求 2 · 三期 3.1 滑动跟手（性能治理）

**验收标准：**

- B1. 滚动中的列表卡片不使用实时背景模糊（backdropBlur），改为静态半透明底色；滚动停止后卡片观感与滚动中肉眼基本无差（真机截图对比确认"几乎看不出区别"）。
- B2. 快速滑动首页（含最近账单列表）和账单列表，不出现肉眼可见的卡顿、跳帧或"跟不上手指"（真机以正常速度快速滑动 10 次，每次均流畅）。
- B3. 卡片阴影改用轻量实现后，浮起感仍在：卡片与背景之间肉眼可分辨出层次，不出现"影子消失、卡片贴平"的观感。
- B4. 图表动画在滚动进行时自动降级（暂停或简化），滚动停止后恢复正常播放；降级与恢复过程无闪烁、无残影。
- B5. 滚动性能有客观改善：与改前版本对比，快速滑动时掉帧明显减少（可用开发者选项"GPU 渲染模式分析"或帧率统计工具辅助验证，改后流畅度主观/客观均优于改前）。
- B6. 上述改动在浅色与深色模式下均成立（两种模式分别验证 B2）。

### 需求 3 · 三期 3.2 财务分析增强

**验收标准（规则部分）：**

- C1. 财务分析新增 4 个维度，每个维度均有明确定义的规则与输出文案：**结余率**（本月结余 ÷ 本月收入）、**支出集中度**（最大分类支出 ÷ 本月总支出）、**储蓄进度**（本月实际结余相对储蓄目标的完成度）、**与上月对比**（本月支出 vs 上月同期支出）。四个维度的计算结果可与手工对账（用同一批账单数据手工计算核对一致）。
- C2. 每个维度对"好 / 中 / 差"三档有明确的分档阈值（写入设计文档供 QA 测试），且文案随分档变化（如结余率高→"存下了大半收入"）。
- C3. 本月收入为 0 或数据不足（如当月 1 号）时，相关维度显示合理文案（如"数据不足，暂无法评估"），不出现 NaN、∞、"0%"误导或崩溃。
- C4. 上月无数据时，"与上月对比"维度给出"上月无数据"类文案，不崩溃、不显示误导性对比。

**验收标准（首页"财务体检"卡）：**

- C5. 首页原"财务状态"卡升级为"财务体检"卡，展示 3~4 行小指标（结余率 / 预算节奏 / 同比等），每行带迷你进度条；每行指标一眼可读（文字+数值+进度条）。
- C6. 进度条与数值一致（如结余率 30% 对应进度条约 30% 长度，肉眼核对误差可忽略）。
- C7. 指标行内容随数据变化而变化（录入一笔大额支出后重进首页，对应指标更新）。

**验收标准（统计页财务小结）：**

- C8. 统计页顶部新增一段财务小结文字（多维度合成的 1~3 句大白话），内容与首页体检卡的指标口径一致、不互相矛盾。
- C9. 小结内容随月份切换而更新（切到上月显示上月的分析）。
- C10. 无数据的月份显示合理空态文案，不崩溃。

### 需求 4 · 三期 3.3 预算重做（三模式）

**功能定义：**

- **模式 A · 先存后花（默认）**：用户只设"每月储蓄目标"；可花额度 = 本月收入 − 储蓄目标；页面展示收入、储蓄目标、已花、剩余可花；已花接近可花额度时提醒。
- **模式 B · 整月上限**：用户设"本月最多花多少"；页面补展示收入、支出、结余三行 + 使用进度。
- **模式 C · 分类预算**：给每个支出分类单独设额度；页面列出各分类的已花/额度 + 总进度。

**验收标准：**

- D1. 预算页顶部有模式切换控件，可在三种模式间切换，当前模式有明确选中态。
- D2. 切换模式后页面立即切换为对应模式的界面与指标，切换过程不崩溃、不显示错误数据。
- D3. 新用户（无历史预算数据）首次进入预算页，默认模式为"先存后花"。
- D4. 【模式 A 计算】可花额度 = 本月收入 − 储蓄目标，与手工计算一致（例：收入 5000 元、储蓄目标 1000 元 → 可花额度 4000.00 元显示正确）。
- D5. 【模式 A 提醒】已花达到可花额度的阈值（接近/达到，具体阈值见设计文档）时，页面出现"再花就存不够了"类提醒；已花未达阈值时不出现提醒。
- D6. 【模式 A 边界】储蓄目标 ≥ 本月收入时，可花额度为 0 或负数，页面显示合理提示（如"储蓄目标已超过本月收入"），不显示负数误导、不崩溃。
- D7. 【模式 B 计算】整月上限模式下，页面展示收入、支出、结余三行，数值与账单实际数据一致；使用进度 = 已花 ÷ 上限，进度条与数字一致。
- D8. 【模式 C 计算】分类预算模式下，每个分类的"已花"按该分类本月实际支出统计（含该分类下所有细分账单），与统计页同一分类的数字一致；未设额度的分类不显示误导性进度。
- D9. 【模式 C 总进度】页面显示各分类已花/额度列表 + 一个总进度（总已花 ÷ 总额度），数值可手工对账。
- D10. 【数据结构】`MonthlyBudget` 扩展 `mode`（枚举 SAVINGS_GOAL / MONTHLY_CAP / CATEGORY）、`savingsGoalCents`、`categoryBudgets`；金额全部以"分"为单位存储。
- D11. 【老数据迁移】只有旧"预算数字"的老用户升级后：原预算数字不丢失、预算功能正常可用（默认迁移为"整月上限"模式，迁移规则写入设计文档），迁移只发生一次、重复打开 App 不重复迁移。
- D12. 【持久化】模式选择与各模式设置值（储蓄目标 / 上限 / 各分类额度）跨 App 重启保持。
- D13. 【金额精度】三模式下所有金额显示与"分"级存储一致，无"差 1 分"类舍入错误（可构造含 0.01 元的账单验证）。
- D14. 三种模式的界面均适配浅色与深色模式，无文字看不清、进度条不可见的问题。

## 五、UI / 交互要点

### 需求 1 · 设置页三开关

- 布局：体验设置区三个 toggle 纵向排列（"操作音效""触觉反馈""Liquid Glass"），样式与现存"减少动态效果"开关一致；"视觉质量"不出现。
- 交互：即点即生效（无需保存按钮）；关闭 Liquid Glass 时页面即时切换为普通卡片风格，无闪烁。

### 需求 2 · 滑动跟手（用户无感，无 UI 变化）

- 原则：这是"看不见的优化"——静态半透明替代实时模糊、阴影轻量化、图表动画滚动降级，三者都要满足"性能变好、观感几乎不变"。观感退化的方案一律不接受（B1、B3 可测）。

### 需求 3 · 财务体检卡 + 统计小结

- 首页"财务体检"卡：3~4 行指标，每行 = 指标名 + 数值 + 迷你进度条（+ 可选趋势箭头）；行内文字层级：指标名小字、数值突出；卡片高度克制，不挤压首页其他卡片。
- 统计页小结：位于统计页顶部、图表区之上，1~3 句大白话（如"本月存下了收入的 35%，比上月多存 8 个点；餐饮占总支出 45%，是最集中的开销"）；纯展示、可点开看细节（如本期做不了展开则纯展示即可，不作为验收项）。

### 需求 4 · 预算三模式

- 布局：预算页顶部为模式切换（分段控件或胶囊组，三选一）；下方为当前模式对应的指标区与编辑入口。
- 模式 A（先存后花）：编辑入口只有"储蓄目标"一个数字；指标区显示 收入 / 储蓄目标 / 已花 / 剩余可花 四项 + 可花额度使用进度条；提醒以页面内提示条形式出现，不用弹窗打断。
- 模式 B（整月上限）：编辑入口为"本月上限"一个数字；指标区显示 收入 / 支出 / 结余 三行 + 使用进度条（沿用现有预算界面逻辑）。
- 模式 C（分类预算）：入口为"设置分类额度"（进入编辑列表，逐分类输入额度）；指标区为各分类 已花/额度 进度行列表 + 顶部总进度条。
- 切换交互：切换模式不弹确认框（数据各模式独立保存，互不覆盖）；切换后指标区即时刷新。
