# Android设计交付区

此目录用于保存下一阶段的高保真页面稿、主题对照稿、组件图板和动效演示，不保存正式账目数据。

当前只完成设计规范，尚未生成视觉原型。原型阶段的预期结构：

```text
design/android/
├─ screens/       页面高保真图
├─ themes/        四套主题对照
├─ components/    组件状态图板
├─ motion/        动效关键帧或演示
└─ prototype/     本地可打开的交互原型
```

视觉原型不会连接正式SQLite数据库，不会读取Windows个人账本，也不属于正式Android代码。
